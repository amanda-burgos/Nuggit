# Nuggit

**ES** · Una app de escritorio que te ayuda a empezar tus tareas, organizarte y no perder el foco. Con widgets, y con **Dip**, un ayudante con IA que convierte una tarea grande en pasitos (los *Tenders*). Y la puedes dejar 100 % a tu gusto.

*A desktop app that helps you start tasks, stay organized and keep your focus. It has widgets, plus **Dip**, an AI helper that breaks a big task into small steps (the Tenders). And you can make it 100 % yours.*

🌎 **Español e inglés** / *Spanish and English*

> Hecha primero para **Mac**. Windows y Linux todavía no se han probado. Mira [Compatibilidad](#-compatibilidad--compatibility).
>
> *Made for **Mac** first. Windows and Linux are untested. See [Compatibility](#-compatibilidad--compatibility).*

## ✨ Qué hace / What it does

- 🧩 **Tablero de widgets**: tareas, notas, reloj, calendario, música, imágenes y más. Despega cualquier widget y ponlo suelto en tu escritorio.
  *Widget board: tasks, notes, clock, calendar, music, images and more. Pop any widget out onto your desktop.*
- 💬 **Dip y los Tenders**: le das una tarea, te hace unas preguntas y te la parte en pasitos. También arma rutinas (Dailies) y ordena un *brain dump*.
  *Dip and the Tenders: give it a task, it asks a few questions and breaks it into steps. It also builds routines (Dailies) and sorts a brain dump.*
- 🎯 **Focus**: rondas para concentrarte, con descansos y tu música.
  *Focus sessions with breaks and your music.*
- ⏰ **Recordatorios** y 💭 **Pregunta del día**.
  *Reminders and a Question of the day.*
- 🎨 **Hazla tuya**: colores, tu propio color, fondos con tus fotos, transparencia, y cada widget con su estilo.
  *Make it yours: colors, your own color, photo backgrounds, transparency, and a style for each widget.*
- 🔤 **Letras**: escoge la fuente de la app y de los títulos, y el tamaño. Incluye fuentes fáciles de leer como **Lexend**, **Atkinson Hyperlegible** y **OpenDyslexic**. Cada widget puede tener su propia letra.
  *Fonts: pick the app's font, a title font and the size. Includes easy-to-read fonts like Lexend, Atkinson Hyperlegible and OpenDyslexic. Each widget can have its own font.*
- 🖱️ **Vestidor del mouse**: viste tu cursor (gatito, pata de gato 🐾, estrella, corazón, Dip…) con los colores que quieras, y ponle una estela de brillitos, estrellitas, corazoncitos y más (hasta 2 a la vez). Guarda tus combos favoritos.
  *Mouse Dress Up: dress up your cursor (kitty, cat paw, star, heart, Dip…) in any colors, add a trail of sparkles, stars, hearts and more (up to 2 at once), and save your favorite combos.*
- 📣 **Te avisa cuando hay una versión nueva** y te enseña lo que cambió.
  *Tells you when a new version is out and shows what changed.*

Las versiones listas para instalar están en la página de [**Releases**](../../releases).

### ⚠️ Antes de abrirla / Before you open it

Nuggit todavía **no está firmada** por Apple ni por Microsoft, así que tu computadora te va a avisar la primera vez. Es normal.

*Nuggit is **not signed** by Apple or Microsoft yet, so your computer will warn you the first time. That's expected.*

- **Mac:** si dice que "no se puede abrir", haz **clic derecho → Abrir → Abrir**, o ve a **Ajustes del Sistema → Privacidad y seguridad → Abrir de todos modos**.<br>
  *If it says it "can't be opened", **right-click → Open → Open**, or go to **System Settings → Privacy & Security → Open Anyway**.*
- **Windows:** si sale "Windows protegió tu PC", toca **Más información → Ejecutar de todas formas**.<br>
  *If you see "Windows protected your PC", click **More info → Run anyway**.*

Descarga Nuggit solo desde este repo.

*Only download Nuggit from this repo.*

### 🔄 Actualizar / Updating

Cuando salga una versión nueva, Nuggit te avisa. Toca **Descargar**, baja el `.dmg` nuevo y arrastra Nuggit a Aplicaciones (dale a **Reemplazar**). Tus tareas, notas y ajustes no se pierden.

*When a new version is out, Nuggit tells you. Click **Download**, get the new `.dmg` and drag Nuggit to Applications (choose **Replace**). Your tasks, notes and settings are kept.*

## 🤖 La IA / The AI

Dip necesita **una** de estas / *Dip needs **one** of these:*

- **Gemini** (en internet): una API key gratis de [Google AI Studio](https://aistudio.google.com/apikey). Lo que le escribes a Dip se manda a Google.<br>
  *Gemini (online): a free API key from Google AI Studio. What you write to Dip is sent to Google.*
- **Ollama** (en tu computadora): gratis y privado, pero necesita una computadora con buena memoria.<br>
  *Ollama (on your computer): free and private, but needs a computer with plenty of memory.*
- **Tu propio servidor** compatible con la API de OpenAI.<br>
  *Your own server that speaks the OpenAI API.*

Sin IA, Nuggit funciona igual, solo que sin Dip.

*Without AI, Nuggit still works, just without Dip.*

## 🔒 Tus datos / Your data

Tus tareas, notas, ajustes y tu API key se guardan **solo en tu computadora**, en la carpeta de datos de la app. Nunca se suben a este repo ni a ningún servidor de Nuggit. Lo único que Nuggit pregunta por internet por su cuenta es si hay una versión nueva en GitHub.

*Your tasks, notes, settings and API key are stored **only on your computer**, in the app's data folder. They are never uploaded to this repo or to any Nuggit server. The only thing Nuggit checks online on its own is whether there's a new version on GitHub.*

## 🛠️ Para desarrolladores / For developers

Necesitas **Node.js 20+** y npm.

*You need **Node.js 20+** and npm.*

```bash
npm install     # la primera vez / first time only
npm run dev     # abre la app en modo desarrollo / opens the app in dev mode
```

Configura la IA copiando `.env.example` a `.env` (nunca subas el `.env`).

*Set up the AI by copying `.env.example` to `.env` (never commit `.env`).*

```bash
npm run typecheck     # revisa los tipos / type check
npm run lint          # revisa el código / lint
npm test              # corre las pruebas / run the tests
npm run build:mac     # crea la app de Mac en dist/ / build the Mac app
npm run build:win     # crea el instalador de Windows / build the Windows installer
npm run build:linux   # crea la versión de Linux / build for Linux
```

**Para publicar una versión:** sube `version` en `package.json` (ej. `1.1.0`), corre `npm run build:mac`, y en GitHub → Releases crea uno con el tag `v1.1.0` y el `.dmg` adjunto.

*To publish a version: bump `version` in `package.json` (e.g. `1.1.0`), run `npm run build:mac`, and create a GitHub Release with the tag `v1.1.0` and the `.dmg` attached.*

La especificación completa y las fases están en [SPEC.md](SPEC.md), y los cambios en [CHANGELOG.md](CHANGELOG.md).

*The full spec and phases are in [SPEC.md](SPEC.md), and the changes in [CHANGELOG.md](CHANGELOG.md).*
